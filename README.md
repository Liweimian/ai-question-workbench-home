# 飞象 AI 组题工作台

一个独立、可运行的 Web 桌面端产品原型。采用 FlowUs / Notion 式可收起组题空间、中间流式编辑画布，以及有题后才出现的 Figma 式右侧辅助信息；页面内 `＋` 统一承接飞象题库、校本题库、上传录题与 AI 创作。

## 终端与预览

- 终端：Web 桌面端
- 推荐宽度：1440px 及以上
- 最小布局宽度：1280px；更窄时按飞象线上规则裁切，不做移动端回流

## 本地启动

```bash
npm install
npm run dev
```

## 构建与预览

```bash
npm run build
npm run preview
```

构建产物位于 `dist/`，Vite 已设置 `base: './'`，可以打包后放到任意静态目录预览。

## 分享方式

1. 本地评审：运行 `npm run dev`，打开终端显示的地址。
2. 文件评审：运行 `npm run build`，压缩 `dist/` 后发给评审人。
3. 新链接发布：评审通过后创建全新的站点身份与链接；禁止复用工作区内任何已有 `.openai/hosting.json`。

## 目录说明

```text
src/
├── components/       产品级组合组件
├── data/             本地 mock 数据
├── design-system/    飞象 token、骨架与 zoom 适配
├── hooks/            工作台状态与交互控制
├── pages/            页面编排
├── prototype/        领域数据类型
└── services/         可替换的 mock 服务边界
```

## 当前原型范围

- 已实现：文档级组题空间（突出新建、我的资源、搜索、最近题单）、空稿 Space 行内 AI、中间流式编辑、有题后显示的右侧题目信息与 AI 改编、飞象/校本题库大弹窗、上传录题、AI 组题、AI 命题、个性化练习、手工录入、排序与撤销。
- 语义区分：AI 组题从已有题库智能挑题并保留来源；AI 命题生成全新题目并标记“AI 原创 · 待校验”。
- 本地 mock：资源与最近题单加载、文件识别、AI 组题 / 命题 / 个性化练习 / 改编、保存和输出。
- 尚未接入：API、鉴权、权限、真实上传、真实 AI、打印/PDF、埋点和线上发布。
