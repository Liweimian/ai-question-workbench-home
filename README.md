# 飞象 AI 题库工作台新首页

一个独立、可运行的 Web 桌面端产品原型。采用 Figma 式“左侧题目 / 中间编辑 / 右侧辅助信息”工作台，并用一个“添加题目”入口承接题库选题、AI 组题、AI 出题、上传录题和手工录入。

## 终端与预览

- 终端：Web 桌面端
- 推荐宽度：1440px 及以上
- 最小布局宽度：1280px；更窄时按飞象线上规则裁切，不做移动端回流

## 本地启动

```bash
npm install
npm run dev
```

## 构建与预览

```bash
npm run build
npm run preview
```

构建产物位于 `dist/`，Vite 已设置 `base: './'`，可以打包后放到任意静态目录预览。

## 分享方式

1. 本地评审：运行 `npm run dev`，打开终端显示的地址。
2. 文件评审：运行 `npm run build`，压缩 `dist/` 后发给评审人。
3. 新链接发布：评审通过后创建全新的站点身份与链接；禁止复用工作区内任何已有 `.openai/hosting.json`。

## 目录说明

```text
src/
├── components/       产品级组合组件
├── data/             本地 mock 数据
├── design-system/    飞象 token、骨架与 zoom 适配
├── hooks/            工作台状态与交互控制
├── pages/            页面编排
├── prototype/        领域数据类型
└── services/         可替换的 mock 服务边界
```

## 当前原型范围

- 已实现：左侧题目定位与历史题单、中间流式编辑、右侧题目信息与 AI 改编、统一添加题目菜单、题库选题、AI 组题、AI 出题预览、上传录题、手工录入、排序与撤销。
- 语义区分：AI 组题从已有题库智能挑题并保留来源；AI 出题生成全新题目并标记“AI 原创 · 待校验”。
- 本地 mock：资源与历史加载、文件识别、AI 组题 / 出题 / 改编、保存和输出。
- 尚未接入：API、鉴权、权限、真实上传、真实 AI、打印/PDF、埋点和线上发布。
